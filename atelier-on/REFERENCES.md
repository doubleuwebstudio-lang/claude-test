# ATELIER ON — 인테리어 사이트 레퍼런스 정리

2026-11-11 기준으로 직접 열어 본 사이트와, 열지 못해 검색 결과로만 확인한 사이트를 나눠 적었습니다.
다른 회사 사이트 화면은 저작권이 있어 이 저장소에 캡처를 넣지 않았습니다.

## 직접 확인한 사이트

### 1. Norm Architects (덴마크, 건축·인테리어) — 시공 사례 목록·상세
- 목록: https://normcph.com/project_category/residential/
- 상세 예시(도쿄 아파트): https://normcph.com/project/azabu-residence/

| 구분 | 본 것 |
|---|---|
| 목록 | 세로형 사진 3~4열. 사진 아래 프로젝트명(넓은 자간), 2~3줄 설명, "분야 / 주거 / 연도" 한 줄. 필터는 분야별 메뉴로만 |
| 상세 첫 화면 | 화면 전체 사진 위에 프로젝트명과 짧은 소개 |
| 상세 본문 | **왼쪽 좁은 칸에 정보(위치·사진가·분류·연도), 오른쪽에 소개글.** 이어서 사진 3장 → 글 → 큰 사진 1장 → 글과 디자이너 인용 → 사진 3장 순서로 글과 사진이 번갈아 나옴 |
| 상세 끝 | "이전 사례 / 다음 사례" 이동, 이 프로젝트 사진 전체 썸네일(Index) |
| 글꼴·색 | 본문도 세리프(Adobe Caslon), 작은 정보는 산세리프(Euclid). 따뜻한 아이보리 배경, 짙은 우드 사진 |
| 시그니처 | 글과 사진을 번갈아 배치하는 잡지식 상세, 사진 톤의 강한 일관성 |

## 아틀리에 온에 가져올 만한 것

1~4번은 2026-11-11에 시안에 반영했습니다. 5~7번은 내용 결정이 필요해 보류 중입니다.

| 순서 | 아이디어 | 출처 | 지금 시안과의 차이 | 아임웹 난이도 |
|---|---|---|---|---|
| 1 | 상세 페이지: 정보를 **왼쪽 칸**에, 소개글을 오른쪽에 두고, 글과 사진을 **번갈아** 배치 | Norm | 지금은 정보 4칸 가로줄 → 글 → 사진 묶음 | 낮음 (컬럼 위젯) |
| 2 | 상세 끝에 **이전 사례 / 다음 사례** 이동 | Norm | 지금은 "전체 시공 사례"로만 돌아감 | 낮음 |
| 3 | 사례 카드에 **한 줄 설명** 추가 | Norm | 지금은 제목과 평형·범위·스타일만 | 낮음 |
| 4 | 진한 색 띠를 마지막 상담 외에 **한 번 더** (예: 업체 소개를 월넛 띠로) | McGee | 지금 진한 띠는 마지막 상담 하나 | 낮음 |
| 5 | 상세에 **"요청 → 해결"** 짧은 블록 (예: "수납이 부족했어요 → 현관·드레스룸 붙박이장") | McGee의 이야기형 상세 | 지금은 소개 2문장뿐 | 낮음 |
| 6 | 사례에 **공사 기간·예산 범위** 표시 | 아파트멘터리 | 없음. 한국 고객이 가장 궁금해하는 정보 | 낮음 (단, 가상 사례라 "예시" 표시 필수, 숫자를 지어내면 안 됨) |
| 7 | **시공 전·후 비교** 사진 | 국내 템플릿 | 없음. 스톡사진으로는 같은 집 전·후 사진을 구하기 어려움 | 중간 |

주의: 5번에서 고객의 말처럼 보이는 인용(후기)은 만들지 않습니다. 기획서 원칙상 검증되지 않은 후기는 쓰지 않으므로, "요청 사항"으로 적고 가상 프로젝트임을 유지합니다.

- 지역 페이지: https://koodadesign.com/interior/geomdan/
- 단지 페이지 예시: https://koodadesign.com/apt/인천-검단-lh20단지 (2026-11-11 확인)

### 본 것

| 구분 | 내용 |
|---|---|
| 사이트 구조 | 지역 페이지 15곳 × 단지 페이지(검단만 129곳)로 "○○ 인테리어" 검색을 노림. 각 페이지에 FAQ·서비스·경로 구조화 데이터(schema.org) |
| 지역 페이지 | 제목 "검단 인테리어, 설계부터 시공까지 한 팀이 맡습니다" → 단지 카드(평면도 썸네일, 일부 참고 사진) → 이 지역에서 일하는 방식(신축 설계 vs 구축 리모델링) → FAQ 7개 → "도면부터 같이 보겠습니다" 상담 |
| 단지 페이지 | 위치·평형·준공연도 정보표 → 공공 데이터(K-apt) 단지 정보와 출처 표기 → 평형별 전형 구조 → **이 단지에서 자주 듣는 고민 4가지**(신축 여부·복도식·소형 평형·주차 조건에서 끌어낸 것) → **등급별 예상 견적**(기본·표준·고급·프리미엄, 자재 이름과 금액대) → 비슷한 단지 → FAQ → 상담 |
| 상담 동선 | 상담 신청서(공사 예정지·평형·예산 범위) → 1~2영업일 내 전화 → 2차 세부 신청서 → 대면 미팅 → 설계 제안·견적 → 계약 → 실측. 견적은 관리사무실 건축도면으로만 냄 |
| 정직한 문구 | "공개 시공 사례는 정리 중", "금액은 예상 · 건축도면·실측 후 확정", "실제와 다를 수 있어 실측 때 다시 확인" |
| 시각 | 제목 Noto Serif KR + 본문 Pretendard, 베이지 바탕, 평면도 썸네일 카드, 짙은 갈색 푸터 |

### 아틀리에 온에 가져올 것

1~3번은 2026-11-11에 반영했습니다 (업체 소개의 자주 묻는 질문, 상담 폼 예산·평면도 항목과 5단계 안내, 서비스 설명의 신축·구축 구분).

| 순서 | 아이디어 | 지금 시안 | 데모에서의 처리 |
|---|---|---|---|
| 1 | **자주 묻는 질문** (비용, 공사 기간, 견적 기준, 진행 방식, 누가 시공하나) | 없음 | 질문 구성은 그대로, 답은 "예시 답변" 표시. 실제 업체 납품 시 업체가 확정 |
| 2 | **상담 폼에 '예산 범위'·'평면도(건축도면) 보유 여부' 추가**, 문의 후 단계를 미팅·견적·실측까지 구체적으로 | 평형·시기만 받음, 3단계 안내 | 선택 항목으로 추가 |
| 3 | **신축 vs 구축** 기준으로 서비스 설명 (신축은 설비를 살리고 주방 동선·수납·조명에 예산, 구축은 전체 리모델링) | 전체 리모델링 / 부분 인테리어 | 서비스 설명 문장에 반영 |
| 4 | 상세 페이지에 **평형별 전형 구조와 그 집의 고민** ("30평대는 보통 방 3·욕실 2 …") | 공간 소개 2문장 + 사진 사이 설명 | 일반적인 구조 설명만 쓰고 수치를 지어내지 않음 |
| 5 | **"금액은 예상", "출처", "정리 중"** 같은 정직한 안내 문구 톤 | 가상 프로젝트·데모 표시는 있음 | 톤 유지 |
| 6 | 견적 **등급표** (기본·표준·고급) | 없음 | 금액은 넣지 않고 등급별 자재 구성만 예시로. 가상 업체가 가격을 공개하면 기획서 원칙 위반 |

### 가져오지 않을 것

- 지역 15곳·단지 129곳 페이지: 데모 범위(고유 페이지 4개, 제작 35시간)를 크게 넘습니다. 실제 고객에게는 **지역·단지 검색용 페이지 묶음을 추가 상품**으로 제안할 수 있습니다.
- 실제 단지 이름·실제 금액대: 가상 업체가 쓰면 허위 정보가 됩니다.
