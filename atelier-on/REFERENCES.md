# ATELIER ON — 인테리어 사이트 레퍼런스 정리

2026-11-11 기준으로 직접 열어 본 사이트와, 열지 못해 검색 결과로만 확인한 사이트를 나눠 적었습니다.
다른 회사 사이트 화면은 저작권이 있어 이 저장소에 캡처를 넣지 않았습니다.

## 직접 확인한 사이트

### 1. Norm Architects (덴마크, 건축·인테리어) — 시공 사례 목록·상세
- 목록: https://normcph.com/project_category/residential/
- 상세 예시(도쿄 아파트): https://normcph.com/project/azabu-residence/

| 구분 | 본 것 |
|---|---|
| 목록 | 세로형 사진 3~4열. 사진 아래 프로젝트명(넓은 자간), 2~3줄 설명, "분야 / 주거 / 연도" 한 줄. 필터는 분야별 메뉴로만 |
| 상세 첫 화면 | 화면 전체 사진 위에 프로젝트명과 짧은 소개 |
| 상세 본문 | **왼쪽 좁은 칸에 정보(위치·사진가·분류·연도), 오른쪽에 소개글.** 이어서 사진 3장 → 글 → 큰 사진 1장 → 글과 디자이너 인용 → 사진 3장 순서로 글과 사진이 번갈아 나옴 |
| 상세 끝 | "이전 사례 / 다음 사례" 이동, 이 프로젝트 사진 전체 썸네일(Index) |
| 글꼴·색 | 본문도 세리프(Adobe Caslon), 작은 정보는 산세리프(Euclid). 따뜻한 아이보리 배경, 짙은 우드 사진 |
| 시그니처 | 글과 사진을 번갈아 배치하는 잡지식 상세, 사진 톤의 강한 일관성 |

### 2. Studio McGee (미국, 주거 인테리어) — 홈·상세
- 홈: https://www.studio-mcgee.com/
- 상세 예시: https://www.studio-mcgee.com/projects/stoneford-cottage

| 구분 | 본 것 |
|---|---|
| 홈 | 짙은 회녹색 띠 안에 액자처럼 놓인 Hero 사진, 아래 한 줄 슬로건(세리프) → 최신 프로젝트 큰 사진 → 글 목록 3열 → **브라운 띠**의 회사 소개 → 언론 인용 → **회녹색 띠**의 포트폴리오 → 숍 |
| 상세 | 사진 위 왼쪽 아래 프로젝트명 → 오른쪽 칸에 짧은 이야기 한 문단 → 사진만 길게. 사진 배치가 전체 폭 / 크기 다른 2장 / 3장으로 계속 바뀜. 정보표는 없음 |
| 글꼴·색 | 제목 세리프(ftBureau), 작은 메뉴·라벨 산세리프(Jost). 크림 배경에 회녹색·브라운 띠를 번갈아 씀 |
| 시그니처 | 진한 색 띠로 섹션 리듬을 만드는 방식, 사진 크기를 계속 바꾸는 상세 갤러리 |

## 열지 못한 사이트 (검색 결과로만 확인)

- **아파트멘터리** https://apartmentary.com/ — 이 환경에서는 페이지가 오류로 열리지 않았습니다. 리뉴얼 사례 소개(Behance)에 따르면 포트폴리오에 **시공 가격·과정·결과를 투명하게 공개**하고, 견적 계산기를 두어 커머스처럼 쓰이게 설계했습니다.
  - https://behance.net/gallery/117395873/Apartmentary-PC-Mobile-Web-UXUI-eXperience-Design
- **국내 인테리어 홈페이지 템플릿(크몽 소개)** — 시공 전후 비교 슬라이더, 평수·공간·예산별 사례 필터, 견적 문의를 함께 두는 구성이 많습니다.
  - https://kmong.com/gig/836752
- **아임웹 인테리어 스튜디오 포트폴리오** — 접근 제한 페이지라 열지 않았습니다. 검색 요약상 여백이 큰 미니멀 레이아웃, 사진을 앞에 둔 프로젝트 페이지입니다.

## 아틀리에 온에 가져올 만한 것

1~4번은 2026-11-11에 시안에 반영했습니다. 5~7번은 내용 결정이 필요해 보류 중입니다.

| 순서 | 아이디어 | 출처 | 지금 시안과의 차이 | 아임웹 난이도 |
|---|---|---|---|---|
| 1 | 상세 페이지: 정보를 **왼쪽 칸**에, 소개글을 오른쪽에 두고, 글과 사진을 **번갈아** 배치 | Norm | 지금은 정보 4칸 가로줄 → 글 → 사진 묶음 | 낮음 (컬럼 위젯) |
| 2 | 상세 끝에 **이전 사례 / 다음 사례** 이동 | Norm | 지금은 "전체 시공 사례"로만 돌아감 | 낮음 |
| 3 | 사례 카드에 **한 줄 설명** 추가 | Norm | 지금은 제목과 평형·범위·스타일만 | 낮음 |
| 4 | 진한 색 띠를 마지막 상담 외에 **한 번 더** (예: 업체 소개를 월넛 띠로) | McGee | 지금 진한 띠는 마지막 상담 하나 | 낮음 |
| 5 | 상세에 **"요청 → 해결"** 짧은 블록 (예: "수납이 부족했어요 → 현관·드레스룸 붙박이장") | McGee의 이야기형 상세 | 지금은 소개 2문장뿐 | 낮음 |
| 6 | 사례에 **공사 기간·예산 범위** 표시 | 아파트멘터리 | 없음. 한국 고객이 가장 궁금해하는 정보 | 낮음 (단, 가상 사례라 "예시" 표시 필수, 숫자를 지어내면 안 됨) |
| 7 | **시공 전·후 비교** 사진 | 국내 템플릿 | 없음. 스톡사진으로는 같은 집 전·후 사진을 구하기 어려움 | 중간 |

주의: 5번에서 고객의 말처럼 보이는 인용(후기)은 만들지 않습니다. 기획서 원칙상 검증되지 않은 후기는 쓰지 않으므로, "요청 사항"으로 적고 가상 프로젝트임을 유지합니다.
