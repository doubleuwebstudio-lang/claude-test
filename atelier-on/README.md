# ATELIER ON — DAY 04 시각 시안

DAY 02 기획서 v2.0과 DAY 03 와이어프레임 v1.0을 기준으로 만든 PC·모바일 시각 시안입니다. 아임웹 제작 전에 색·글꼴·배치를 확인하기 위한 정적 HTML입니다.

`index.html`을 브라우저로 열면 됩니다. 페이지는 홈, 시공 사례, 상세(`project-30.html`, `project-20.html`, `project-40.html`, 공통 코드 `detail.js`), 업체 소개, 상담 문의입니다.

## 핵심 요소: 평면도

- 서비스 안내에서 공사 범위를 평면도 위에 색으로 표시합니다(전체 리모델링 / 부분 인테리어).
- 상세 페이지의 평면 개념도에서 공간 이름을 누르면 해당 사진으로 이동하고, 사진과 방이 서로 강조됩니다.
- 아임웹에서는 평면도를 SVG 또는 PNG 이미지로 넣고, 방 연결은 앵커 링크로 대체할 수 있습니다.

## 주의

- 사진은 Pexels 무료 이미지(작가 Max Vakhtbovych)입니다. 프로젝트마다 같은 집을 찍은 세트를 썼고, 후보와 선택 이유는 `photo-candidates.html`에 있습니다.
  - 30평대: 6933852~6933860 / 20평대: 6890394~6890401 / 40평대: 7005285~7005300
  - Pexels 라이선스상 출처 표기는 필수가 아니지만, 가상 프로젝트임을 분명히 하려고 푸터와 상세 페이지에 출처를 적었습니다.
  - 실제 고객 업체 사이트에는 쓰지 않습니다. 남의 집 사진이 그 업체의 시공 실적처럼 보이게 됩니다.
- 사진 색감은 `tools/grade.py`로 통일했습니다. 벽·천장의 흰색을 같은 따뜻한 흰색(R:G:B ≈ 1.025:1:0.955)으로 맞추고, 밝기·대비·채도를 같은 기준으로 맞춥니다. 우드 색은 건드리지 않습니다.
  - 원본 가장자리에 붙은 어두운 띠(몇 픽셀)는 자동으로 잘라 냅니다.
  - 원본은 `images/original/`에 있습니다. 사진을 바꾸면 원본 폴더에 넣고 `python3 tools/grade.py`를 다시 실행합니다.
  - 아임웹에는 보정된 `images/*.jpg`만 올립니다.

## 섹션 리듬

- 홈 시공 사례: 큰 사진 1장 + 작은 사진 2장 (태블릿은 큰 1장 + 아래 2장, 모바일은 1열)
- 홈 업체 소개: 화면 전체 폭 사진 위에 글 상자를 겹침
- 홈·업체 소개 마지막 상담 안내: 차콜 띠
- 상세 갤러리: 전체 폭 → 반반 → 전체 폭 (세로로 긴 사진은 반반 자리에 배치)
- 아임웹 구현: 큰 사진 1장 + 2장 배치와 반반 갤러리는 컬럼 위젯 비율 조정으로, 글 상자 겹침은 섹션 위 여백을 음수로 주는 CSS 한 줄이 필요합니다.
- 모든 시공 사례는 가상 프로젝트로 표시했고, 사업자 정보는 넣지 않았습니다.
- 상담 폼은 입력 확인만 하며 아무것도 전송·저장하지 않습니다.
