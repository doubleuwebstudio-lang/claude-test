# ATELIER ON — DAY 04 시각 시안

DAY 02 기획서 v2.0과 DAY 03 와이어프레임 v1.0을 기준으로 만든 PC·모바일 시각 시안입니다. 아임웹 제작 전에 색·글꼴·배치를 확인하기 위한 정적 HTML입니다.

`index.html`을 브라우저로 열면 됩니다. 페이지는 홈, 시공 사례, 상세(`detail.html?p=p01|p02|p03`), 업체 소개, 상담 문의입니다.

## 디자인 토큰

| 이름 | 값 | 용도 |
|---|---|---|
| 벽지 화이트 | `#FAF9F6` | 페이지 배경 |
| 석고 | `#F0ECE5` | 교차 섹션 배경 |
| 베이지 | `#D8C8AE` | 공사 범위 표시, 보조 강조 |
| 오크 | `#7C5D3E` | 링크, 현재 메뉴 |
| 차콜 | `#2A2826` | 본문, 버튼 |
| 스톤 | `#6A645C` | 보조 글자 |

- 글꼴: IBM Plex Sans KR (300/400/500/600), `word-break: keep-all`
- 본문 17px / 행간 1.75, Hero 제목 30~56px, 상세 제목 26~40px
- 버튼 높이 48px 이상, 입력창 52px, 모서리 3px

## 핵심 요소: 평면도

- 서비스 안내에서 공사 범위를 평면도 위에 색으로 표시합니다(전체 리모델링 / 부분 인테리어).
- 상세 페이지의 평면 개념도에서 공간 이름을 누르면 해당 사진으로 이동하고, 사진과 방이 서로 강조됩니다.
- 아임웹에서는 평면도를 SVG 또는 PNG 이미지로 넣고, 방 연결은 앵커 링크로 대체할 수 있습니다.

## 주의

- 사진 영역은 **사진 자리**입니다. 실제 사진(또는 생성 이미지)으로 교체합니다.
- 모든 시공 사례는 가상 프로젝트로 표시했고, 사업자 정보는 넣지 않았습니다.
- 상담 폼은 입력 확인만 하며 아무것도 전송·저장하지 않습니다.
