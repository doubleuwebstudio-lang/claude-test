# ATELIER ON — DAY 04 시각 시안

DAY 02 기획서 v2.0과 DAY 03 와이어프레임 v1.0을 기준으로 만든 PC·모바일 시각 시안입니다. 아임웹 제작 전에 색·글꼴·배치를 확인하기 위한 정적 HTML입니다.

`index.html`을 브라우저로 열면 됩니다. 페이지는 홈, 시공 사례, 상세(`project-30.html`, `project-20.html`, `project-40.html`, 부분 인테리어 `project-partial.html`, 공통 코드 `detail.js`), 업체 소개, 상담 문의입니다.

## 핵심 요소: 평면도

평면도는 홈 첫 화면(공간별 사진 보기)과 업체 소개의 부분 인테리어 설명에만 있고, 시공 사례 목록·상세에는 넣지 않습니다. 실제 업체 사례에서 구조가 바뀐 경우에는 실제 도면으로 공사 전·후 평면도를 넣는 것을 권합니다.

### 도면 그리기
- `main.js`의 `ARCH`(30평대 예시)와 `archPlan()`이 건축 도면 표기법으로 그립니다: 외벽 7·내벽 3 두께, 문 열림 호, 창(가는 세 줄), 발코니, 거실·주방·식탁 사이의 열린 경계(점선).
- 홈 첫 화면은 왼쪽 글과 도면, 오른쪽 사진입니다. 첫 방문 때(PC) 도면의 벽과 문이 그려지고, 이어서 우드 슬랫처럼 세로 띠 여섯 줄이 차례로 걷히며 사진이 드러납니다. 도면의 모든 방에 마우스를 올리면(키보드 초점·클릭 포함) 그 공간 사진으로 바뀌고 방이 칠해집니다. 거실·주방·식탁은 같은 집 사진, 나머지 방은 다른 사례 사진이며 사진 이름표에 출처 사례를 표시합니다. 동작 줄이기 설정이면 효과 없이 완성된 상태로 보입니다.
- 아임웹: 도면은 SVG 이미지로 내보내 이미지 위젯에 넣으면 됩니다. 첫 화면은 2단 컬럼(글+도면 이미지 / 사진)으로 구현합니다.

### 메인 "공간 고르기"
- 부분 인테리어 / 전체 리모델링을 고르고, 부분 인테리어에서는 공간 사진 카드 6장(거실·주방·식탁·안방·침실·욕실·현관) 중 하나를 고릅니다. 도면은 홈 첫 화면 한 곳에서만 씁니다.
- 오른쪽에 그 공간의 사진 2장, 많이 하는 공사, 그 공간이 나오는 사례가 나옵니다.
- 전체 리모델링을 고르면 평면도 대신 일반적인 공사 순서 9단계(철거 → 설비·방수 → 창호 → 목공 → 전기·조명 → 타일 → 도배·바닥 → 가구·주방 → 마감·청소)가 나오고, 오른쪽에 포함되는 공사와 예시 기간(FAQ와 같은 6~8주)이 나옵니다. 단계별 기간은 넣지 않습니다.
- "선택한 공간으로 상담하기"를 누르면 상담 폼의 문의 내용이 "주방, 욕실 부분 인테리어 상담을 원합니다."처럼 미리 채워집니다 (브라우저 세션 저장소 사용, 막혀 있으면 빈 칸).
- 아임웹: 코드 위젯 필요(난이도 중~상). 대안은 탭 위젯 + 평면도 이미지 (선택·미리 채우기 기능은 빠짐).
- 공간 데이터와 자주 묻는 질문은 `main.js`의 `SPACES`, `FAQ`에서 한 번에 고칩니다 (메인은 질문 3개, 상담 문의는 전체).


- 업체 소개의 부분 인테리어 설명에 공사 범위 예시(주방·욕실)를 평면도 위에 빗금으로 표시합니다.

## 섹션 리듬

- 홈 시공 사례: 큰 사진 1장 + 작은 사진 2장 (태블릿은 큰 1장 + 아래 2장, 모바일은 1열)
- 홈 업체 소개: 화면 전체 폭 사진 위에 글 상자를 겹침
- 홈·업체 소개 마지막 상담 안내: 차콜 띠
- 상세 갤러리: 전체 폭 → 반반 → 전체 폭 (세로로 긴 사진은 반반 자리에 배치)
- 아임웹 구현: 큰 사진 1장 + 2장 배치와 반반 갤러리는 컬럼 위젯 비율 조정으로, 글 상자 겹침은 섹션 위 여백을 음수로 주는 CSS 한 줄이 필요합니다.
- 모든 시공 사례는 가상 프로젝트로 표시했고, 사업자 정보는 넣지 않았습니다.
- 상담 폼은 입력 확인만 하며 아무것도 전송·저장하지 않습니다.
