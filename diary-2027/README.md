# 2027 디지털 다이어리

굿노트·노타빌리티용 하이퍼링크 PDF 다이어리 생성기입니다.

```bash
node diary-2027/build.js ENFP
```

- `out/2027-diary-ENFP.pdf`: 판매용 파일 (90쪽, 탭·날짜 링크 2,598개). 저장소에는 올리지 않습니다.
- `out/preview-ENFP/`: 상세페이지용 속지 미리보기 8장
- `out/thumbnail-ENFP.png`: 상품 썸네일 (1500×1500)

## 구성
표지 → 사용법 → 연간 달력 → 올해 목표 → 월간 12 → 주간 53 → 습관 트래커 12 → 아이디어 주차장 4 → 메모 5.
모든 속지 오른쪽 탭으로 이동하고, 월간 달력의 날짜를 누르면 그 주 주간 페이지로 갑니다.

## 다른 유형 추가하기
`types.js`에 유형 하나를 추가하면 같은 구조로 만들어집니다. 색은 성향 묶음으로 맞춥니다: NF 초록, NT 보라, SJ 파랑, SP 노랑.
