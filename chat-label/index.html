우리 대화 성분표

대화 파일을 올리면 누가 먼저 연락하는지, 답장은 얼마나 빠른지, 얼마나 웃는지 성분표처럼 정리해 드려요.

.txt, .csv, .zip 파일을 여기로 끌어다 놓아도 됩니다.

대화는 이 기기 브라우저 안에서만 읽고 계산합니다. 서버로 보내거나 저장하지 않아요.

파일 대신 대화 내용 붙여넣기

대화 파일 꺼내는 법 메일 없이

  1. 채팅방 오른쪽 위 ≡ 메뉴 → 아래 ⚙ 설정
  2. 대화 내용 내보내기 → 모든 메시지 내부저장소에 저장
  3. 여기서 대화 파일 고르기 → 내 파일 → KakaoTalk → Chats → KakaoTalk_Chats로 시작하는 폴더 안의 .txt 파일
  1. 채팅방 오른쪽 위 ≡ 메뉴 → 아래 ⚙ 설정
  2. 대화 내용 내보내기 → 모든 메시지 도큐멘트로 저장하기
  3. 여기서 대화 파일 고르기 → 파일 앱에서 방금 저장한 파일. .zip 압축 파일도 그대로 올리면 됩니다.
  1. PC 카카오톡에서 채팅방을 열고 Ctrl+S (맥은 ⌘+S)
  2. 또는 채팅방 메뉴 → 대화 내보내기
  3. 저장된 .txt 파일을 왼쪽으로 끌어다 놓기

메뉴 이름은 카카오톡 버전마다 조금 다를 수 있어요. 사진이 같이 저장돼도 괜찮아요, 대화 글만 읽어요. 단체방도 됩니다.
