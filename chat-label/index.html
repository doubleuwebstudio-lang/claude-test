우리 대화 성분표

대화 파일을 올리면 누가 먼저 연락하는지, 답장은 얼마나 빠른지, 얼마나 웃는지 성분표처럼 정리해 드려요.

.txt 또는 .csv 파일을 여기로 끌어다 놓아도 됩니다.

대화는 이 기기 브라우저 안에서만 읽고 계산합니다. 서버로 보내거나 저장하지 않아요.

파일 대신 대화 내용 붙여넣기

대화 파일 꺼내는 법

  1. 휴대폰: 채팅방 오른쪽 위 메뉴 → 설정 → 대화 내용 내보내기 → 텍스트만 보내기 → 파일 저장
  2. PC: 채팅방 메뉴 → 대화 내보내기 → .txt 저장
  3. 저장한 파일을 왼쪽에 올리면 끝.

단체방도 됩니다. 비교할 두 사람을 고를 수 있어요.

    버튼이 안 되면 이미지를 길게 눌러 저장하세요.

    2,900원 예정

    성격 유형은 대화 습관으로 추정한 재미용 결과이며, 공식 성격검사가 아닙니다.

    대화 파일은 업로드한 기기에서만 처리되고, 창을 닫으면 사라집니다.
